## Wastely (EcoScan)

An AI-powered waste-sorting app that classifies items as trash or recycling from a photo, using Claude's vision API. Originally developed as EcoScan — a computer vision and mechanical sorting prototype — and rebuilt as a full web app with gamification to encourage correct sorting.

### What Was Built

* Built a sorting prototype in which a computer vision classifier drives an Arduino-controlled servo mechanism that routes each item to trash or recycling
* Built a full-stack web app: React/TypeScript client, Express server, Supabase (PostgreSQL) for auth and data
* Integrated Claude's vision API to classify photographed items in real time
* Added user accounts, points, streaks, and a leaderboard to gamify correct recycling
* Built a JSON/CSV impact report grouped by GRI 306 waste categories for institutional ESG tracking
* Deployed the app (Render backend, Vercel frontend) with PWA support for mobile installation
* Filed a provisional patent and became a Diamond Challenge semifinalist for the underlying EcoScan concept

### Technologies

`React` `TypeScript` `Express` `Supabase` `PostgreSQL` `Claude API` `Computer Vision` `Arduino` `PWA`

## Drowning Detection System

A computer vision-based safety prototype designed to identify potential drowning behavior and automatically trigger a physical alert.

### What Was Built

* Built a browser-based computer vision proof of concept that uses camera hand-position detection as a proxy for distress behavior
* Converted the model's output into a binary control signal
* Wired an Arduino Uno and SG90 servo to that signal to trigger an automated physical alert
* Designed the system as a proof of concept for automated pool safety monitoring, clearly separate from a validated drowning-recognition system

### Technologies

`Computer Vision` `Arduino Uno` `SG90 Servo` `Hardware Prototyping`

## Duds Studio

An automated video production and publishing pipeline built to grow my YouTube channel, producing edits that have earned thousands of views.

### What Was Built

* Built a Python pipeline that turns images and clips into 60 fps short-form edits with layered visual effects
* Synced every cut to a drum hit using neural beat tracking (beat_this) and Demucs drum-stem separation
* Wrote an automated quality checker that compares each render frame by frame against a reference edit (cut timing, audio sync, blur, frozen or black frames) and generates PASS/WARN/FAIL reports
* Automated publishing through the YouTube Data API with OAuth; uploads stay private until approved
* Built a Flask dashboard to manage media, rendering, preview, and upload

### Technologies

`Python` `PyTorch` `OpenCV` `FFmpeg` `MoviePy` `Flask` `YouTube Data API`
