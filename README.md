## Wastely (EcoScan)

An AI-powered waste-sorting app that classifies items as trash or recycling from a photo, using Claude's vision API. Originally developed as EcoScan — a computer vision and mechanical sorting prototype — and rebuilt as a full web app with gamification to encourage correct sorting.

### What Was Built

* Built a full-stack web app: React/TypeScript client, Express server, Supabase for auth and data
* Integrated Claude's vision API to classify photographed items in real time
* Added user accounts, points, streaks, and a leaderboard to gamify correct recycling
* Deployed the app (Render backend, Vercel frontend) with PWA support for mobile installation
* Filed a provisional patent and became a Diamond Challenge semifinalist for the underlying EcoScan concept

### Technologies

`React` `TypeScript` `Express` `Supabase` `Claude API` `Computer Vision` `PWA`

**Live demo:** [wastely-client-ten.vercel.app](https://wastely-client-ten.vercel.app/)
**Full code:** [github.com/aarav253/Wastely](https://github.com/aarav253/Wastely)

## Drowning Detection System

A computer vision-based safety prototype designed to identify potential drowning behavior and automatically trigger a physical alert system.

### What Was Built

* Developed a vision-based system for detecting signs of potential drowning
* Connected the detection software to a physical alert mechanism
* Prototyped hardware using a camera, Raspberry Pi, speaker, and servo-based components
* Designed the system to operate as a proof of concept for automated pool safety monitoring

### Technologies

`Python` `Computer Vision` `Raspberry Pi` `OpenCV` `Arduino` `Hardware Prototyping`

### What Was Built

* Allowed users to describe a training scenario using natural language
* Converted user instructions into an interactive virtual environment
* Designed the platform to make customized employee training simulations faster and easier to create
